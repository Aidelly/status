Aidelly system status

Live status for Aidelly and for the social platforms we publish to.
This page is hosted independently of Aidelly's own infrastructure, so it stays up when we do not.
Platform APIs are shown so you can tell whether a publishing problem is ours or the network's. These checks detect outright outages and cannot see partial degradation, so a green platform is not a guarantee that every endpoint behind it is healthy.
Checks run every five minutes. Service credits under the Agency SLA apply to App and dashboard and Publishing only.
